# Adasa 📷

My 14th assignment and my first Angular assignment during the Front-End Development track at Route Academy.

I built the UI and styling from scratch and developed the application logic using Angular and TypeScript.

## ✨ Features

* Responsive photography blog website
* Home page
* Blog articles
* Article details
* Category filtering
* Grid and List views
* Angular routing
* 404 Not Found page
* Responsive design

## 🛠️ Technologies

* HTML5
* CSS3
* TypeScript
* Angular
* Tailwind CSS
