# Adasa 📷

My 14th assignment and my first Angular assignment during the Front-End Development track at Route Academy.

I built the UI and styling from scratch and developed the application logic using Angular and TypeScript.

## ✨ Features

* Search articles by title or description
* Filter articles by category
* Switch between Grid and List views
* View article details
* Navigate between Home and Blog using Angular Routing
* Responsive design

## 🛠️ Technologies

* HTML5
* CSS3
* TypeScript
* Angular
* Tailwind CSS
* Angular Router
* FormsModule
